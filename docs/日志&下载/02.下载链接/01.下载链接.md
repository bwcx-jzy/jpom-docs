::: danger 安全提示：请下载 2.11.13 或更高版本
**2.11.12 及更早版本存在已修复的安全漏洞**（含 CVE-2026-120201 等，最高 CVSS 9.8），请使用下方 **2.11.13** 安装包，或通过“系统管理 → 在线升级”升级。

- [查看 2.11.13 安全公告（CVE 列表、升级方式与注意事项）](/pages/security/2.11.13/)
- 旧下载域名 **`d.jpom.download` 已停用**（无法访问），请使用新域名 **`d2.jpom.download`**；本页所有链接均已指向新域名。
- 请从官方页面进入下载，谨防仿冒站点：详见[下载说明](/pages/malice-fraudulent/)
:::

:::tip 下载说明
为提供更稳定的下载服务，我们已取消下载授权中心，全面采用 Cloudflare R2 提供下载，下载地址：[https://d2.jpom.download](https://d2.jpom.download)

**请大家友好使用下载服务，谢谢！**
:::

::: warning 下载中心历史版本保留策略
为保障下载服务稳定并控制存储成本，下载中心**仅保留 2.11.x 稳定版与最新 beta** 安装包；2.10.x 及更早版本的安装包已全部下架，对应历史下载页的链接已失效。
:::
