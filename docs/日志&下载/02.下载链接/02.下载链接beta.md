:::tip 下载说明
为提供更稳定的下载服务，我们已取消下载授权中心，全面采用 Cloudflare R2 提供下载，下载地址：[https://d2.jpom.download](https://d2.jpom.download)

**请大家友好使用下载服务，谢谢！**
:::

:::tip 安装包格式说明
过渡期版本仍附带 `.zip` 兼容包（仅用于兼容旧版本在线升级），新安装请优先下载 `.tar.gz`；切换为仅提供 `.tar.gz` 的具体版本以更新日志/下载页为准。

自本页最新版本起，**不再提供 server+agent 聚合包 `jpom-<version>.tar.gz`**（server/agent 各自的 `*-release.tar.gz` 与 sha1 保留，下载页直接列出，按需分别下载）；Go 升级容器也不再单独发布 linux-amd64 兼容别名 `agent-go-<version>-upgrade.jar`，请按节点平台下载 `agent-go-<version>-upgrade-<os>-<arch>.jar`。
:::

:::tip Go 插件端（可选，单二进制、免 JDK）
本页每个版本段落除 Java 服务端/插件端安装包外，还提供 Go 插件端安装包：
`agent-go-<version>-release-<os>-<arch>.tar.gz`，平台覆盖 linux-amd64、linux-arm64、darwin-amd64、darwin-arm64、windows-amd64。
在线升级使用对应平台的容器包 `agent-go-<version>-upgrade-<os>-<arch>.jar`，平台必须与节点一致（linux-amd64 兼容别名 `agent-go-<version>-upgrade.jar` 已不再发布）。
使用说明：[Go 插件端安装与部署](/pages/go-agent/install/) / [在线升级与回滚](/pages/go-agent/upgrade/)。
:::
