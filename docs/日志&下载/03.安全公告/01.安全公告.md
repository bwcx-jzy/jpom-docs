# Jpom 安全公告

> 本页是 Jpom 官方安全公告的统一入口，用于集中发布已修复安全问题的**受影响版本、修复版本、升级方式与防护建议**。
> 公告只描述修复与防护信息，**不包含漏洞利用细节**。

## 最新公告

### 2.11.13 安全修复公告（2026-11-07）

::: danger 请尽快升级
**Jpom 2.11.12 及更早版本均受本次安全问题影响**，其中包含 CVSS 9.8 的严重问题。
**2.11.13 已完整修复**，请使用旧版本的用户尽快升级。
:::

## 维护与支持说明

- Jpom 自 **2026-02-05** 起暂停**常规功能迭代**，但**安全维护仍在继续**；安全问题的评估与修复不受“暂停维护”影响。
- 安全修复只针对最新稳定版发布。本次修复版本为 **2.11.13**，建议所有使用 2.11.12 及更早版本的用户升级；继续使用旧版本将无法获得后续安全修复。
- 安全问题请优先邮件报告：**bwcx_jzy@dromara.org**；请勿在公开 issue 中粘贴未修复漏洞的利用细节、凭据或内网信息。非敏感的低危问题可以先提 issue 讨论。

## 如何获取安全更新

1. **在线升级（推荐）**：登录服务端 → 系统管理 → 在线升级，检查并升级到 `2.11.13`；插件端可在节点管理中批量升级。
2. **手动下载**：在[下载中心](/pages/all-downloads/)下载 `2.11.13` 安装包（`d2.jpom.download`），升级步骤见[升级版本](/pages/FQA/upgrade/)。
3. **Docker 镜像**：`jpomdocker/jpom:2.11.13`、`jpomdocker/jpom-agent:2.11.13`（`latest` 自 2026-11-07 起指向 2.11.13）。
4. **发行版页面**：[Gitee Release](https://gitee.com/dromara/Jpom/releases/tag/v2.11.13) ｜ [GitHub Release](https://github.com/dromara/Jpom/releases/tag/v2.11.13)。

::: tip 提示
升级前请阅读公告中的“升级注意事项”，并提前备份数据目录与配置文件。
:::
