# Go 插件端配置说明

> 适用版本：提供 Go 插件端的 Jpom 版本。
> 核心原则：Go 插件端与 Java 插件端使用**同一份** `conf/application.yml` 和**同一个** `data/` 目录，切换时**不需要改配置、不需要迁移数据**。

## 1. 配置文件位置与加载

| 项 | 说明 |
| --- | --- |
| 默认路径 | `<安装目录>/conf/application.yml` |
| 自定义路径 | 启动参数 `-conf <file>`（等价 Java 的 `-Dspring.config.location`） |
| 安装根目录 | 默认由可执行文件位置推断（`<安装目录>/bin/agent` → `<安装目录>`）；也可用 `-base <dir>` 指定，或配置 `jpom.path` |
| 生效方式 | 修改后重启插件端生效（Server 上「系统管理 → 插件端配置」在线保存等价于直接改该文件） |

```bash
# 查看当前生效的配置（只读）
cat /opt/jpom/agent/conf/application.yml
# 指定配置文件与安装目录启动（一般由服务脚本/服务托管，不需要手工带参数）
/opt/jpom/agent/bin/agent -base /opt/jpom/agent -conf /opt/jpom/agent/conf/application.yml
```

:::tip 从 Java 插件端迁移
直接用 Java 插件端的 `conf/application.yml` 即可，无需删改键；Go 插件端只读取自己用到的键，其余键忽略。
:::

## 2. 常用配置项

以下键与 Java 插件端语义一致（完整键见 Java 插件端默认配置文件）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `server.port` | 2123 | 插件端监听端口；多实例/并行验证时改为其它端口（如 2124） |
| `server.address` | 空（0.0.0.0） | 绑定地址 |
| `jpom.path` | 空 | 数据根目录；为空时使用安装目录 |
| `jpom.authorize.agent-name` | jpomAgent | 鉴权账号，**必填** |
| `jpom.authorize.agent-pwd` | 空 | 鉴权密码；为空时自动生成并保存到 `data/agent_authorize.json` |
| `jpom.init-read-line` | 10 | 查看日志时首次回放的行数 |
| `jpom.system.lang` | 空 | 默认语言（zh-CN / en-US 等）；空则跟随请求语言/系统 |
| `jpom.system.log-charset` | UTF-8 | 插件端系统日志读取编码（系统日志页面/WS 日志） |
| `jpom.system.console-charset` | 空 | 脚本与命令输出编码；Windows 建议 GBK |
| `jpom.system.old-jars-count` | 2 | 升级备份保留个数（`bin/oldJars`） |
| `jpom.system.allowed-downgrade` | false | 是否允许在线升级降级（回滚旧版本时需要） |
| `jpom.system.command-use-sudo` | false | 执行系统命令是否自动加 sudo（需免密） |
| `jpom.system.timer-match-second` | false | 定时任务是否支持秒级（6/7 段 cron） |
| `jpom.project.status-wait-time` | 10 | 项目启停等待秒数 |
| `jpom.project.status-detection-interval` | 500 | 项目状态检测间隔（毫秒） |
| `jpom.project.file-backup-count` | 0 | 项目文件备份保留个数（大于 0 才开始备份） |
| `jpom.project.log.file-charset` | 空（Windows=GBK） | 项目控制台日志读写编码 |
| `jpom.project.log.save-days` | 7 | 控制台日志备份保留天数 |
| `jpom.project.log.auto-backup-size` | 50MB | 控制台日志超过该大小自动备份 |
| `jpom.monitor.network.stat-contains-only-names` | 空 | 监控只统计的网卡（支持 `en*` 通配，逗号分隔） |
| `jpom.monitor.network.stat-exclude-names` | 空 | 监控排除的网卡（如 `lo*`） |
| `spring.servlet.multipart.max-file-size` | 5MB | 单文件上传上限（分片上传的单片大小由 Server 决定，默认 1MB） |
| `spring.servlet.multipart.max-request-size` | 20MB | 请求总大小上限 |

:::tip 三个日志/输出编码项的区别
- `jpom.system.log-charset`：插件端**系统日志**（「插件端日志」页面 / 系统日志 WebSocket）的读取编码，默认 UTF-8；
- `jpom.system.console-charset`：脚本执行与系统命令**输出**的读取编码，Windows 建议 GBK；
- `jpom.project.log.file-charset`：**项目控制台日志**读写的编码（Windows 默认 GBK，其它系统默认 UTF-8；项目级 `logCharset` 可覆盖）。

三者都应与实际输出编码一致，否则页面会出现乱码；修改后需重启插件端生效。
:::

## 3. 数据目录布局

默认在安装目录下（若配置了 `jpom.path`，则相对该目录）：

```text
<安装目录>/
├── conf/application.yml
├── bin/agent、bin/AgentGo.sh
├── data/
│   ├── INSTALL.json            # 安装 ID（勿删）
│   ├── agent_authorize.json    # 自动生成的鉴权账号（勿泄露）
│   ├── project.json             # 项目数据
│   ├── script.json              # 脚本模板
│   ├── script_log.json          # 脚本执行记录（待同步）
│   ├── whitelistDirectory.json  # 授权目录/可编辑后缀
│   ├── workspace_env_var.json   # 工作空间环境变量
│   ├── global-script/           # 脚本库
│   ├── script/<脚本ID>/log/     # 脚本执行日志
│   ├── project_file_backup/     # 项目文件备份
│   ├── script_run_cache/        # 脚本运行临时文件
│   ├── remote_version.json      # 远程版本缓存
│   └── temp/                    # 临时文件（分片上传等）
├── logs/                        # 插件端运行日志
├── project-log/<项目ID>/         # 项目控制台日志（未自定义 logPath 时）
└── tmp/                          # 临时目录
```

:::warning 数据目录兼容
以上文件与 Java 插件端**完全一致**，切换后 Server 端看到的项目、脚本、环境变量、授权目录不会丢失。切换前后可用仓库中的 `go-agent/script/verify-switch-data.sh` 做结构对比（见「Java 与 Go 平滑切换」）。
:::

## 4. 鉴权说明

插件端与 Server 之间使用请求头 `Jpom-Agent-Authorize` 鉴权，值为：

```text
sha1(agentName + "@" + agentPwd)   # 小写十六进制
```

- 在 Server 的「机器资产」中填写的账号/密码就是 `agentName` / `agentPwd`；
- 密码为空时，插件端首次启动会生成随机密码并写入 `data/agent_authorize.json`（权限 600），可在该文件查看（**不要在聊天/工单/截图中暴露**）；
- 修改了 `agent-name` 但沿用旧 `agent_authorize.json` 时插件端会启动失败（提示已有登录名与配置不一致），需先删除该文件或同步修改 Server 机器资产。

## 5. 与 Java 插件端的差异（用户可见）

| 项 | Java 插件端 | Go 插件端 |
| --- | --- | --- |
| 运行依赖 | 需要 JDK 8+ | 单个二进制，无需 JDK |
| 内存占用 | JVM 固定开销较大 | 常驻内存显著更低 |
| 启动脚本 | bin/Agent.sh | bin/AgentGo.sh（建议保留 Agent.sh 以便回切） |
| 升级包 | Agent-<version>.jar | agent-go-<version>-upgrade.jar（Go 升级容器包） |
| 监控中的 JDK 相关字段 | javaVersion/totalMemory/freeMemory 有值 | 对应字段为空/0（页面仅展示，不影响功能） |
| 项目启动 | 调用系统 java | 调用系统 java（**需自行配置 JAVA_HOME/PATH**） |

:::tip 关于 pluginSize 等展示字段
Go 插件端没有 Java 的插件机制，系统缓存/首页里的个别统计字段（如 pluginSize）与 Java 版可能不同，但不影响任何功能。
:::

## 6. 环境变量（可选）

| 变量 | 说明 |
| --- | --- |
| `JAVA_HOME` / `PATH` | 运行 Java 项目必需，让插件端进程能执行 java |
| `JPOM_LOG` | 指定日志目录（等价 Java 插件端） |
| `JPOM_LANG` | 默认语言（等价 jpom.system.lang） |
| `JPOM_SERVICE` | 使用 systemd 时填写服务名，便于升级后由服务管理器拉起 |

## 7. 修改配置的建议流程

1. 低风险项（如 `init-read-line`、监控网卡）：直接改 `conf/application.yml` → `bin/AgentGo.sh restart`；
2. 端口/鉴权相关：先改配置，再同步修改 Server 端机器资产，最后重启插件端；
3. 变更前先备份：

```bash
tar czf ~/jpom-agent-conf-$(date +%Y%m%d-%H%M).tgz -C /opt/jpom/agent conf data
```

:::danger 不要同时编辑同一份数据目录
插件端运行期间不要用其它程序（包括另一个版本的插件端）写同一份 `data/` 与 `conf/`。
:::
