# 反向连接隧道（插件端主动连接服务端）

> 适用版本：2.11.14.2-beta 及以上

默认情况下，Jpom 由**服务端主动访问插件端**（HTTP 2123 端口 + WebSocket）来管理节点，因此服务端必须能直连插件端。插件端在 NAT 后面、没有公网 IP、或者不允许对外开放端口时，就只能做端口映射或打通 VPN。

反向连接隧道把方向反过来：**插件端主动拨号连接服务端**，服务端不再需要能访问插件端的任何端口。插件端只要**能出站访问服务端**即可工作。

## 一、工作方式

- 服务端只暴露一个 WebSocket 入口 `/agent/tunnel`；
- 插件端启动后主动连接该入口，用**连接密钥 + 节点标识**完成握手，之后定期心跳表示在线；
- 服务端需要调用插件端时（节点状态、项目管理、构建、文件、控制台、日志、在线升级等），通过这条连接下发请求，插件端把请求转发到**本机接口**后回传结果；
- 未配置反向隧道时，Jpom 行为与升级前完全一致（服务端主动拉取）。

## 二、服务端配置

在服务端 `conf/application.yml` 中增加：

```yaml
jpom:
  agent:
    tunnel:
      # 连接密钥，配置后才会启用 /agent/tunnel 端点；留空表示不启用
      key: 请替换为足够复杂的随机字符串
      # 未注册节点是否允许自动注册（默认 false：直接拒绝）
      allow-auto-register: false
      # 心跳间隔（秒）
      heartbeat-seconds: 5
```

修改后**重启服务端**生效。启动日志出现「反向连接隧道已启用」表示端点已就绪。

> 连接密钥要妥善保存：它是插件端接入的唯一凭据。泄露后可在服务端更换密钥并重启，旧密钥立即失效。

## 三、插件端配置

在插件端 `conf/application.yml` 中增加（Java 与 Go 插件端使用**同一份配置**）：

```yaml
jpom:
  tunnel:
    # 服务端隧道地址，支持 ws:// 与 wss://；可只写到主机，路径会自动补 /agent/tunnel
    server-url: wss://jpom.example.com
    # 与服务端 jpom.agent.tunnel.key 完全一致
    key: 请替换为与服务端相同的密钥
    # 本插件端在服务端「机器节点资产」中的标识（machineId）
    machine-id: 机器节点ID
    # 回环请求超时（秒）
    timeout-seconds: 30
```

三项（`server-url`、`key`、`machine-id`）齐全才启用。日志出现 `tunnel connected` 表示已连上。

## 四、接入步骤

1. 服务端配置 `jpom.agent.tunnel.key` 并重启，确认日志出现「反向连接隧道已启用」；
2. 插件端配置上面三项并重启，确认日志出现 `tunnel connected`；
3. 服务端日志出现「节点 xxx 反向隧道上线」，说明通道已可用；
4. 机器节点资产里的 **jpomUrl 不再被使用**，可以留空或保留原值：只要该节点的隧道在线，服务端请求就走隧道；隧道离线时自动回退为直连（直连不通就会提示节点不可用）。

> 如果开启了 `allow-auto-register: true`，未知节点标识首次连接时会自动创建一条机器节点资产记录，之后可在「资产管理」里分配工作空间、绑定为业务节点。

## 五、检查与排障

| 现象 | 排查方向 |
| --- | --- |
| 服务端日志没有「反向连接隧道已启用」 | 检查 `jpom.agent.tunnel.key` 是否为空（空值不启用），是否已重启 |
| 插件端日志报「连接密钥不正确」 | 两端 `key` 不一致 |
| 插件端日志报「握手签名校验未通过」 | 两端系统时间相差超过 5 分钟，请校准时间 |
| 插件端日志报「节点未注册」 | 机器节点资产里没有该 `machine-id`；先创建，或开启 `allow-auto-register` |
| 节点显示离线 | 检查插件端到服务端 443/2122 的出站连通性；确认 `server-url` 的协议（`ws`/`wss`）与端口正确 |

服务端还提供两个查询接口，便于自查：

- `GET /tunnel/online`：返回当前通过隧道在线的机器节点标识列表；
- `GET /tunnel/status?machineId=xxx`：返回指定节点是否通过隧道在线。

## 六、注意事项

- **在线升级**：升级会重启插件端进程，隧道会断开。反向模式下页面上的升级进度可能停在“重连中”，插件端重启并自动重连后节点恢复在线，刷新页面即可。
- **未注册节点**：默认拒绝接入。开启自动注册只创建机器节点资产，是否作为业务节点使用仍需在服务端确认。
- **密钥与安全**：建议使用 `wss://`（经反向代理终止 TLS）。连接密钥与插件端管理密码相互独立，可分别重置。
