Jpom 提供两种把 AI 接入日常运维的方式，**都不修改、也不嵌入 Jpom 主程序**，默认只读：

- **MCP Server（推荐）**：npm 包 `jpom-mcp-server`，通过 MCP stdio 把 Jpom 的 REST 能力暴露给 Claude Desktop、Cursor、VS Code、DeepSeek Harness 等支持 MCP 的客户端；需要 Node.js ≥ 18。
- **jpom-ops Skill（备选）**：无需 Node.js，仅需 Python 3.8+（标准库），通过 REST 脚本完成查询与受控写操作。

::: warning 安全提示
- 长期 token（请求头 `JPOM-USER-TOKEN`）只放本地环境变量或 `chmod 600` 的本地文件，**不要提交到仓库、写进 URL 或截图传播**。
- 两种方式默认**只读**；写操作（触发构建、启停项目、杀进程、在线升级）必须显式开启，并在执行前回显环境/对象、获得明确同意。
- 请按**工作空间最小权限**创建 token，并在正确环境（开发/测试/生产）操作；Jpom 操作日志可用于审计。
:::

## 支持方式

| 方式 | 状态 | 适用工具 |
|---|---|---|
| MCP Server（`jpom-mcp-server`） | 可用（0.1.x，npm，stdio） | Claude Desktop、Cursor、VS Code、DeepSeek Harness 等 MCP 客户端 |
| `jpom-ops` Skill（指令 + REST 脚本） | 可用（REST 全能力，只读默认） | DeepSeek Harness、Claude、Cursor、其他可加载指令/执行脚本的 Agent |

MCP Server 与 Skill 都调用 Jpom 现有 REST API，兼容 Jpom 2.11.x。

## MCP Server（推荐）

### 前置条件

- Jpom Server 2.11.x（默认端口 2122，地址以实际部署为准）
- Node.js **≥ 18**（`node -v` 检查）
- Jpom 长期 token：在 Jpom【用户管理 → 对应用户 → 长期 token】生成；建议单独创建一个最小权限用户/token 给 AI 使用

### 安装与自检

无需克隆仓库，直接用 `npx` 运行：

```bash
# 版本
npx -y jpom-mcp-server --version

# 连通性自检（token 从 600 权限文件读取，避免写进命令历史）
JPOM_BASE_URL=http://127.0.0.1:2122 \
JPOM_TOKEN_FILE=/path/to/jpom-token \
npx -y jpom-mcp-server doctor
```

`doctor` 成功时输出 JSON，包含 `"ok": true`、`baseUrl`、`workspace`、`"readOnly": true`、`workspaces` 与节点总数 `nodeTotal`。

也可以全局安装：

```bash
npm install -g jpom-mcp-server
jpom-mcp-server --version
```

> npm 包页面：<https://www.npmjs.com/package/jpom-mcp-server>；源码：Jpom 仓库 `mcp-server/` 目录。

### 配置项

| 环境变量 | 必填 | 说明 |
|---|---|---|
| `JPOM_BASE_URL` | 是 | Jpom Server 地址，例如 `http://127.0.0.1:2122`；不要带尾斜杠 |
| `JPOM_TOKEN` | 二选一 | Jpom 长期 token；与 `JPOM_TOKEN_FILE` 同时存在时优先 |
| `JPOM_TOKEN_FILE` | 二选一 | 存放 token 的文件路径（建议 `chmod 600`） |
| `JPOM_WORKSPACE` | 否 | 工作空间 ID，默认 `DEFAULT` |
| `JPOM_READ_ONLY` | 否 | 默认 `true`；设为 `false` 才允许写工具 |
| `JPOM_TIMEOUT_MS` | 否 | 请求超时，默认 60000 |
| `JPOM_MAX_RESULT_CHARS` | 否 | 单次工具结果最大字符数，默认 50000 |
| `JPOM_VERIFY_SSL` | 否 | 默认 `true`；仅自签名测试环境临时设为 `false` |

### MCP 客户端配置

所有客户端都要在配置的 `env` 中注入上述环境变量（客户端启动 server 时不会继承终端里的全部变量），并把 token 换成自己的长期 token。

#### Claude Desktop

配置文件：macOS `~/Library/Application Support/Claude/claude_desktop_config.json`；Windows `%APPDATA%\Claude\claude_desktop_config.json`。修改后完全退出并重启 Claude Desktop。

```json
{
  "mcpServers": {
    "jpom": {
      "command": "npx",
      "args": ["-y", "jpom-mcp-server"],
      "env": {
        "JPOM_BASE_URL": "http://127.0.0.1:2122",
        "JPOM_TOKEN": "<YOUR_JPOM_LONG_TERM_TOKEN>",
        "JPOM_WORKSPACE": "DEFAULT",
        "JPOM_READ_ONLY": "true"
      }
    }
  }
}
```

#### Cursor

项目级 `.cursor/mcp.json` 或全局 `~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "jpom": {
      "command": "npx",
      "args": ["-y", "jpom-mcp-server"],
      "env": {
        "JPOM_BASE_URL": "http://127.0.0.1:2122",
        "JPOM_TOKEN": "<YOUR_JPOM_LONG_TERM_TOKEN>",
        "JPOM_WORKSPACE": "DEFAULT",
        "JPOM_READ_ONLY": "true"
      }
    }
  }
}
```

#### VS Code

工作区级 `.vscode/mcp.json`（注意字段是 `servers`，stdio 需显式 `type`）：

```json
{
  "servers": {
    "jpom": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "jpom-mcp-server"],
      "env": {
        "JPOM_BASE_URL": "http://127.0.0.1:2122",
        "JPOM_TOKEN": "<YOUR_JPOM_LONG_TERM_TOKEN>",
        "JPOM_WORKSPACE": "DEFAULT",
        "JPOM_READ_ONLY": "true"
      }
    }
  }
}
```

> DeepSeek Harness 的 MCP 配置是插件配置树（YAML，`@deepseek-ai/dsh-mcp-client`），不是 `mcpServers` JSON；示例见源码 `skills/jpom-ops/adapters/dsh/README.md`。

### 工具能力

MCP Server 提供 54 个工具（47 个只读 + 6 个受控写 + 1 个通用 REST 调用），按域覆盖：

| 域 | 主要能力 |
|---|---|
| 节点 | 节点/分组、监控数据、进程列表、机器信息 |
| 项目 | 节点上的项目列表与详情 |
| 构建 | 构建配置/详情/历史/分组、仓库与分支 |
| 脚本 | 服务端脚本与节点脚本、执行记录 |
| 资产 | 机器、SSH、FTP、Docker 资产 |
| 监控与分发 | 项目监控、分发任务与执行日志 |
| 系统 | 系统信息、版本检查、备份、集群、受管日志 |
| 用户与审计 | 用户、权限组、登录日志、操作日志、最近操作 |
| 日志 | 系统/节点日志快照与实时跟随、项目日志、构建/脚本日志行游标 |

日志类工具按“快照 + 游标 + 有界跟随”设计，适合 AI 上下文：

- 先 `jpom_system_log_files` 找文件，再用 `jpom_system_log_read` 取尾部或按关键词过滤（默认最多处理 5 MiB）；
- 构建/脚本日志用 `jpom_build_log` / `jpom_script_log` / `jpom_node_script_log`，按返回的 `nextLine` 继续读；
- `jpom_system_log_follow` / `jpom_project_log_follow` 只收集短时窗口（默认 3 秒、最多 15 秒），不是无限流。

### 写操作（默认禁用）

写工具在 `JPOM_READ_ONLY=true`（默认）时直接拒绝，且不会发出请求；需要时显式改为 `false`：

| 工具 | 说明 |
|---|---|
| `jpom_build_start` / `jpom_build_cancel` / `jpom_build_rerelease` | 触发/取消/按历史重发构建 |
| `jpom_project_operate` | 项目启停重启（start/stop/restart） |
| `jpom_node_kill_pid` | 结束节点上的进程（高危） |
| `jpom_system_upgrade` | 在线升级（最高风险，可能重启 Server） |

::: warning
开启写操作前请确认当前环境（开发/测试/生产）、工作空间、对象 ID 与动作；优先使用最小、可回滚的操作，执行后再回读状态确认。不要把 `JPOM_READ_ONLY` 长期设为 `false`。
:::

### 常见问题

- **`doctor` 返回 `code=800`**：token 无效或已过期（修改密码后旧 token 失效），重新生成长期 token。
- **返回 `code=999`**：权限不足，检查 token 用户的工作空间与权限组、`JPOM_WORKSPACE` 是否正确。
- **连接失败/超时**：检查 `JPOM_BASE_URL`、端口、Jpom 是否启动、context-path、网络/代理；`JPOM_TIMEOUT_MS` 过小也会超时。
- **客户端看不到 `jpom_*` 工具**：查看客户端 MCP 日志与 server 的 stderr；确认 `command/args` 可执行、Node ≥ 18、`env` 已注入、修改配置后客户端已重启。
- **结果被截断**：缩小 `limit`/`maxLines`、使用日志的 `grep`/关键词过滤，或分段读取。

## jpom-ops Skill（备选）

如果运行环境没有 Node.js，可使用 Skill 方式：通过 `jpom_api.py`（Python 3.8+，仅标准库）调用 Jpom REST API。

- 下载 Skill 包：[/downloads/ai-skills/jpom-ops-skill.zip](/downloads/ai-skills/jpom-ops-skill.zip)
- 源码：Jpom 仓库 `skills/jpom-ops/`
- 使用：把 `SKILL.md` 作为 AI 工具的项目指令/规则，并允许其执行 `scripts/jpom_api.py`

### 快速开始

```bash
export JPOM_BASE_URL=http://127.0.0.1:2122
export JPOM_TOKEN_FILE=/path/to/jpom-token   # chmod 600；或使用 JPOM_TOKEN
export JPOM_WORKSPACE=DEFAULT

./scripts/jpom-api.sh capabilities           # 能力清单
./scripts/jpom-api.sh workspaces             # 校验 token
./scripts/jpom-api.sh nodes
./scripts/jpom-api.sh build-history
```

Windows（cmd / PowerShell）：

```bat
set JPOM_BASE_URL=http://127.0.0.1:2122
set JPOM_TOKEN_FILE=C:\path\jpom-token
set JPOM_WORKSPACE=DEFAULT
python scripts\jpom_api.py capabilities
python scripts\jpom_api.py nodes --limit 5
```

### 能力与写操作

| 域 | 命令 |
|---|---|
| 工作空间 | `workspaces` `workspace-list` `workspace-env` |
| 节点 | `nodes` `node-groups` `node-machine-info` `node-monitor` `node-process` |
| 项目 | `projects` `project-info` |
| 构建 | `builds` `build-get` `build-history` `build-log` `build-groups` `repositories` `repository-groups` `branches` |
| 脚本 | `scripts` `scripts-all` `script-logs` `node-scripts` `node-script-logs` |
| 资产 | `machines` `ssh-assets` `ftp-assets` `docker-assets` |
| 监控/分发/系统 | `monitors` `dispatch` `dispatch-logs` `system-info` `check-version` `server-logs` `backups` `clusters` |
| 用户与审计 | `users` `permission-groups` `login-logs` `operate-logs` `recent-logs` `log-read` |

写操作默认禁用（`JPOM_OPS_ALLOW_WRITE=true` + `--confirm`）：`build-start`、`build-cancel`、`build-rerelease`、`project-operate`、`node-kill-pid`、`system-upgrade`。

### 不在范围

终端（SSH / Docker CLI / 节点控制台）、脚本在线执行、文件浏览与上传、用户/权限/系统配置写操作——属于 WebSocket 交互通道或高风险管理面，不适合交给 AI 自动执行；MCP Server 同样不提供这些能力。

## 选择建议

| 场景 | 推荐方式 |
|---|---|
| Claude Desktop / Cursor / VS Code 等原生 MCP 客户端 | **MCP Server** |
| DeepSeek Harness / 已有 Skill 体系的 Agent | MCP Server 或 Skill 均可 |
| 机器上没有 Node.js（只有 Python） | Skill |
| 需要工具级参数校验、结构化结果、默认只读闸门 | MCP Server |
