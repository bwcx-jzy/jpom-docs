# 2.11.15.3-beta (2026-11-26)

# 🐣 新增功能

  1. 【server】新增 流水线触发器：开放接口可按 token 触发运行、查询最近一次运行状态
  2. 【web-vue】新增 流水线列表「触发器」入口，可复制触发地址并重置
  3. 【server】【agent】新增 版本检查超时时间可用 JPOM_REMOTE_VERSION_TIMEOUT 配置（默认 10 秒）
  4. 【server】【web-vue】新增 流水线发布方式支持「文件中心」，产物存入文件中心可再分发或下载
  5. 【server】【web-vue】新增 流水线事件钩子：按事件选择服务端脚本，脚本输出实时写进运行日志
  6. 【server】【web-vue】新增 流水线 webhook 通知：多地址、按事件过滤、GET/POST、失败重试一次
  7. 【server】【web-vue】新增 流水线事件钩子支持选「全部事件」，不用逐个勾选
  8. 【server】【web-vue】新增 SSH 终端会话录制与回看：资产开关控制，可按命令跳转回放
  9. 【server】新增 流水线仓库源本地缓存：同仓库同引用同深度的后续运行只做增量拉取，不再每次全量克隆

# 🐞 解决BUG、优化功能

  1. 【server】修复 生成触发器地址时传了不存在的 id 报 500 程序错误，现在提示「没有对应数据」
  2. 【server】优化 触发器地址统一走同一套生成逻辑，构建、脚本、SSH 命令、环境变量、文件存储等 10 类触发器的校验与提示一致
  3. 【server】【web-vue】修复 流水线触发器「查询状态」地址缺参数打不开，现在可直接查看运行状态
  4. 【server】优化 流水线运行状态改为受控转换，终态不可再被改写，非法转换写日志并标注
  5. 【server】优化 流水线通知脚本输出实时写入运行日志，取消运行能终止正在执行的脚本
  6. 【web-vue】优化 流水线页面配色改用主题变量，暗色/紧凑主题与系统一致，不再是白底黑字
  7. 【web-vue】优化 流水线编辑改为步骤指示器（仓库源/阶段编排/事件通知），阶段配置可拖拽调宽，操作按钮固定在抽屉底部
  8. 【web-vue】优化 代码编辑器只保留深/浅两档皮肤并按系统主题自动识别，不再需要手动选皮肤
  9. 【web-vue】优化 流水线阶段配置表单标签列改为按像素分档，面板拖窄自动竖排，不再左侧大片空白
  10. 【server】【web-vue】优化 流水线分组改为与构建/项目一致的虚拟逻辑分组下拉框，可选已有、可在下拉内新增，列表分组筛选改精确下拉
  11. 【server】修复 使用新分组字段（groupName）的表启动时不再漏修空分组：NULL/空串统一归到「默认」分组
  12. 【web-vue】修复 发布失败帮助仍写脚本非 0 只记录，现指向「其他配置 → 严格执行」口径
  13. 【server】修复 流水线「克隆深度」不生效（未切系统 git，参数被丢弃），现真实浅克隆并写进运行日志
  14. 【web-vue】优化 流水线「克隆深度」帮助写明需服务端安装 git，未安装时深度不生效
  15. 【server】修复 流水线触发器用纯 token（不带登录会话）调用时报「没有对应的用户」，现按 token 所属用户执行

# 2.11.15.2-beta (2026-11-25)

# 🐞 解决BUG、优化功能

  1. 【server】修复 开启「严格执行」时 SSH 发布命令/SSH 项目重启退出码读取不到（-1）仍判成功，现按该目标失败处理
  2. 【web-vue】修复 发布前/后命令帮助仍写「返回非 0 不参与发布判定」，现按「严格执行」开关实际口径说明

# ⚠️ 升级说明

  1. 严格执行口径补齐：开启「严格执行」的 SSH / SSH 项目构建，发布命令或重启脚本退出码读取不到（-1）时不再当作成功，会判该目标失败；未开启该开关的构建行为不变。

  1. 权限收紧（需要管理员确认）：以下接口现在要求对应工作空间的方法权限（此前仅有登录/节点数据权限即可访问），升级后如提示“没有对应管理权限”，请到【用户管理 → 权限组】为相关用户的工作空间勾选对应权限；超级管理员不受影响：
    • 证书管理 → 证书导出：需要 DOWNLOAD（下载）权限；
    • 节点项目文件备份：下载需要 DOWNLOAD，删除需要 DEL，创建/恢复备份需要 EDIT。
  2. 列表数据范围恢复：项目列表、节点脚本列表、文件中心、静态文件存储、证书、仓库、脚本列表/执行记录、环境变量等“全局/工作空间共享”列表恢复为仅展示**当前工作空间 + 全局（GLOBAL）**数据；此前因工作空间过滤条件失效会显示其他工作空间数据（本次为安全修复，非故障）。
  3. 触发器 token 格式校验：文件下载、构建/脚本/SSH/项目/环境变量等触发器 token 仅接受字母数字 6~128 位；标准 32 位十六进制（当前版本）和历史 10 位字母数字 token 兼容。若仍在使用更早期非标准格式 token 且升级后提示无效，请重置该触发器 token。
  4. 文件中心下载接口参数语义：
    • sort 仅接受文件记录的真实字段（如 createTimeMillis:desc），非法字段会被忽略；

    • 按别名下载时按“别名 + token”精确匹配；同一别名对应多个文件时，以 token 实际绑定的记录为准。

  6. 无数据库表结构/字段变更，无需手工迁移；升级前仍建议按惯例备份 data/conf。
  7. WebSocket 鉴权与日志安全收紧：
    • WebSocket 改用登录会话（HttpOnly Cookie）认证，不再支持在 URL 中传 userId=密码摘要；前端已同步适配，升级后建议刷新页面；自定义 WebSocket 客户端需先登录或调用任意接口获取会话 Cookie，并按与页面同源的 Origin 连接；非浏览器客户端也可改用 Authorization（JWT）或 JPOM-USER-TOKEN（长期 token）请求头认证。
    • WebSocket 现在同样受 IP 访问限制；禁用账号无法建立新的 WebSocket 连接；已经建立的连接不会因账号随后被禁用而立即断开（重连时会校验）。
    • 系统日志、插件端日志、项目日志的 WebSocket 日志文件名限制在日志/项目目录内，防止路径穿越与符号链接逃逸；若自定义日志文件不在默认日志/项目目录，可能无法通过 WebSocket 实时查看（安全收紧）。
    • 反向代理需保留 Host（或设置 X-Forwarded-Host）并允许 WebSocket Upgrade；否则同源校验可能拒绝连接（浏览器直连/常规 Nginx 反代无需额外配置）。

    • 【节点&项目 → 项目列表】导出、【在线构建 → 仓库信息】导出：仅导出当前工作空间 + GLOBAL数据（此前不受当前空间限制）；需要其它空间数据时请切换工作空间后分别导出；
    • 仓库分组下拉、SSH 终端执行日志列表现在按当前工作空间过滤（系统管理员同样受当前空间约束）；

    • 非时间字段带 [0]/[1] 的过滤参数将被忽略（不再返回 500）。
  9. 数据库异常提示变化：数据库类异常统一返回通用错误提示，不再在接口响应中展示 SQL/列名/表名等细节；排查时请查看服务端日志（完整堆栈仍会记录）。正常业务/参数/权限异常提示不变。
